Learning Outcomes
=================

By the end of this tutorial, you will be able to:

#. Build and run applications for profiling on Gadi.
#. Identify function hotspots and call paths with **gprof**.
#. Analyze CPU, threading, and memory performance with **Intel VTune**.
#. Detect memory errors and leaks with **Valgrind Memcheck**.
#. Examine function costs, cache behavior, and heap usage with **Callgrind**,
   **Cachegrind**, and **Massif**.
#. Collect and explore parallel application profiles with **HPCToolkit**.
#. Inspect CUDA kernels, memory transfers, and CPU activity with
   **NVIDIA Nsight Systems**.
#. Choose the appropriate tool and use its reports to guide improvements.
